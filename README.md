# AWS SAA Labs

This repository contains hands-on lab exercises to practice for the AWS Certified Solutions Architect - Associate (SAA) exam.

Purpose

- Provide small, focused labs to explore AWS services and common SAA topics (compute, storage, networking, databases, security, and more).

Contents

- Terraform and configuration files used in the labs are placed in subfolders (for example, `common/`).

Usage

- Review each lab folder, follow the lab instructions, and make a Terraform script to run these

Notes

- This repo is for personal study and practice only and is not affiliated with AWS.
- The labs concerning the Infrastructure as Code Part use CloudFormation. For training purposes only Terraform will be used.
